MacKVM 使用手冊

讓兩台 MacBook Pro 共用一組鍵盤、滑鼠與 BenQ MA270U 螢幕的 macOS 選單列工具。

1. 開始前

M5 Pro MacBook Pro
使用 dist/arm64/MacKVM.app。
2019 Intel MacBook Pro
使用 dist/x86_64/MacKVM.app。
  • 兩台 Mac 都需 macOS 13 或更新版本，並連接到同一個本機網路。
  • 兩台 Mac 都要安裝並執行 MacKVM。
  • 在兩台 Mac 的「顯示器」設定中，將 MA270U 設為主要顯示器。
首次開啟提示：目前 app 使用 ad-hoc 簽章，並非 Apple Developer ID 公證版本。若 macOS 阻擋，請在 Finder 對 MacKVM.app 按右鍵，選擇「打開」，再於提示視窗確認。

2. 安裝與啟動

  1. 將正確架構的 MacKVM.app 複製到該 Mac 的 /Applications。
  2. 雙擊開啟。MacKVM 不會顯示在 Dock，而是在螢幕右上方選單列顯示雙螢幕圖示。
  3. 點擊雙螢幕圖示開啟 MacKVM 選單。
  4. 若希望登入後自動啟動，在選單中啟用 Launch MacKVM at Login。

若你需要在 M5 Pro 上自行重建兩個版本：

cd MacKVM
./scripts/build-app.sh --arch arm64
./scripts/build-app.sh --arch x86_64

3. MA270U 螢幕與線材設定

電腦建議連線MacKVM preset
M5 Pro MacBook ProMA270U USB-C 視訊／資料／90 W 連接埠M5 / USB-C preset
2019 Intel MacBook ProHDMI 1（USB-C／Thunderbolt 轉 HDMI）Intel / HDMI preset
  1. 在 MA270U 的螢幕選單（OSD）啟用 DDC/CI，如該選項可用。
  2. 在 M5 Pro 安裝選用的自動切換工具：brew install m1ddc。
  3. 在 M5 Pro 選擇 M5 / USB-C preset；在 Intel Mac 選擇 Intel / HDMI preset。
  4. 先以 Show this Mac 與 Show other Mac 確認切換，再開始遠端控制。

若 Intel Mac 接在 HDMI 2，請將所有對應的輸入選擇改成 HDMI 2。Intel Mac 不支援由 m1ddc 自動切換，切換失敗時請用 MA270U OSD 手動選擇輸入來源。

4. 授權 macOS 權限

MacKVM 需要兩台 Mac 都授權 Input Monitoring 與 Accessibility，才能傳送和接收鍵盤／滑鼠操作。區域網路權限則在探索另一台 Mac 時由 macOS 提示。

  1. 出現設定提示時，點擊 Request Permissions。
  2. 依 macOS 提示授權第一項權限。
  3. 完全退出並重新開啟 MacKVM，再授權下一項。每次啟動只要求一項，避免系統提示重疊。
  4. 兩項權限都顯示 Granted 後，再開始控制。

如果之前按過拒絕、macOS 沒再跳出提示，請在 MacKVM 選單該權限列使用 Settings，然後在系統設定中手動允許 MacKVM。

5. 探索、配對與控制

  1. 確認兩台 Mac 都開著 MacKVM，並在選單的 Nearby Macs 看見對方。
  2. 在其中一台按 Pair。
  3. 比較兩邊的六位數驗證碼是否相同，並確認各自顯示的「對方」裝置名稱正確後，兩邊都按 Accept。
  4. 配對完成後按 Connect。
  5. 在控制端選擇 Request control of other Mac。只要接收端的 Accessibility 已授權，MacKVM 便會自動授予控制，接著即可使用本機鍵盤及滑鼠操作另一台 Mac。

第一次配對後，裝置的公開金鑰會被保存。若看到不預期的裝置名稱或驗證碼不一致，請按 Decline。

6. 日常操作與安全返回

  • 控制另一台 Mac 時，本機鍵盤與滑鼠輸入會被轉送；收到 MacKVM 的自動授權前，不會開始抑制本機輸入。
  • 要結束控制，按選單的 Return input to this Mac。
  • 緊急停止快捷鍵：Control-Option-Command-Escape。
  • 網路中斷時，MacKVM 會立刻把鍵盤與滑鼠控制歸還本機，並釋放可能按住的按鍵和滑鼠按鈕。
  • 想移除已配對裝置，選擇 Forget；之後要重新配對才能連線。

7. 常見問題

看不到另一台 Mac

確認兩台都在同一 Wi-Fi／乙太網路、MacKVM 正在執行，並在 macOS 提示時允許「本機網路」。公司或訪客網路可能阻擋 Bonjour 探索。

無法控制，或按鍵沒有反應

確認兩台 Mac 都已授權 Input Monitoring 和 Accessibility，且兩台裝置已完成配對並顯示已連線。

螢幕沒有自動切換

先在 M5 Pro 執行 brew install m1ddc，確認 USB-C 連接 MA270U、OSD 的 DDC/CI 已開啟；仍失敗時用螢幕 OSD 手動選 USB-C 或 HDMI。

登入後沒有出現圖示

先手動啟動 MacKVM，在選單中重新開啟 Launch MacKVM at Login，並檢查「系統設定 → 一般 → 登入項目」是否需要核准。
