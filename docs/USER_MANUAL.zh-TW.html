MacKVM 0.12.2

MacKVM 使用手冊

提供選單列入口與一般控制視窗，讓兩台 MacBook Pro 共用一組鍵盤、滑鼠，並可選擇切換 BenQ MA270U 螢幕的 macOS app。

1. 開始前

M5 Pro MacBook Pro
使用 dist/arm64/MacKVM.app。
2019 Intel MacBook Pro
使用 dist/x86_64/MacKVM.app。
  • 兩台 Mac 都需 macOS 13 或更新版本，並連接到同一個本機網路。
  • 兩台 Mac 都要安裝並執行 MacKVM。
  • 外接螢幕不是配對或遠端控制的必要條件；只有 DDC 切換與跨螢幕指標定位才需要。
首次開啟提示：目前 app 使用 ad-hoc 簽章，並非 Apple Developer ID 公證版本。若 macOS 阻擋，請在 Finder 對 MacKVM.app 按右鍵，選擇「打開」，再於提示視窗確認。

2. 安裝與啟動

  1. 將正確架構的 MacKVM.app 複製到該 Mac 的 /Applications。
  2. 雙擊開啟。MacKVM 會顯示在 Dock 並提供一般控制視窗，也會在選單列顯示 KVM／雙螢幕圖示。
  3. 可從 Dock 視窗或選單列圖示開啟控制。
  4. 若希望登入後自動啟動，在選單中啟用 Launch MacKVM at Login。
  5. 由登入項目自動啟動時會隱藏完整視窗以免搶走焦點；需要時可從選單列圖示或 Dock 重新開啟。

若你需要在 M5 Pro 上自行重建兩個版本：

cd MacKVM
./scripts/build-app.sh --arch arm64
./scripts/build-app.sh --arch x86_64

要建立 DMG，可使用：

./scripts/package-dmg.sh --arch universal
./scripts/verify-release.sh --app dist/universal/MacKVM.app --arch universal
(cd dist && shasum -a 256 -c MacKVM-0.12.2-universal.dmg.sha256)

DMG 會從乾淨的暫存目錄建立，並在旁邊產生可攜式 SHA-256 檔案；驗證結果應顯示 OK。

未提供 Developer ID 時是 ad-hoc 簽章，只適合本機測試；跨電腦散布前請用 --sign "Developer ID Application: …" --require-developer-id， 並完成 Apple notarization。

3. 實體鍵盤／滑鼠路徑（P0）

目前接線的重點：HDMI 只傳送影像，不會把 MA270U 的 USB hub 上游提供給 2019 Intel Mac。預設請把鍵盤與滑鼠接在 M5 Pro（直接接，或接 MA270U USB hub），讓 Intel Mac 作為可被控制的目標。
  1. 在 MacKVM 的 Physical input path 保持 One keyboard on M5 Pro (USB-C)。
  2. 這個模式會允許 M5 Pro 發起控制，並在 Intel Mac 上停用發起控制按鈕； Intel Mac 仍然可以接收遠端控制。
  3. 若使用實體 USB switch，先確認兩台 Mac 的 macOS 都能看到同一組鍵盤與 滑鼠，再在兩台選擇 External USB switch (bidirectional)。 app 無法從軟體偵測 switch 是否真的存在。

4. MA270U 螢幕與線材設定

電腦建議連線MacKVM preset
M5 Pro MacBook ProMA270U USB-C 視訊／資料／90 W 連接埠M5 / USB-C preset
2019 Intel MacBook ProHDMI 1（USB-C／Thunderbolt 轉 HDMI）Intel / HDMI preset
  1. 部分 MA270U 韌體不會在 OSD 顯示 DDC/CI 開關；MacKVM 會在 macOS 暴露顯示器時使用原生 bridge。
  2. MacKVM 使用原生 IOKit DDC/CI：Apple Silicon 走 IOAVService，Intel 走 IOI2C，不需要 Homebrew 工具。
  3. 在任一台 Mac 按 Detect DDC-capable displays，明確選取要控制的螢幕。MacKVM 保存原生穩定識別碼，不會假設螢幕永遠是編號 1。
  4. 在 M5 Pro 選擇 M5 / USB-C preset；在 Intel Mac 選擇 Intel / HDMI preset。MA270U 的 EDID mapping 會把 USB-C 傳成 VCP 19（0x13），HDMI 1 傳成 VCP 17（0x11）；其他型號使用自己的韌體 mapping，依賴新型號前先執行診斷掃描。
  5. 先以 Show this Mac 與 Show other Mac 確認切換。M5 Pro 可按 Share keyboard and mouse with [Intel Mac] 一次切換畫面並分享鍵盤滑鼠；Intel Mac 只有在未啟用該配對裝置的無縫控制時才需按 Allow。若原生探索或切換失敗，先閱讀 DDC diagnostic 並確認線材直接連接，再使用 OSD 備援。

若 Intel Mac 接在 HDMI 2，請將所有對應的輸入選擇改成 HDMI 2。螢幕與線材必須提供 DDC/CI；切換失敗時請查看診斷並用螢幕 OSD 手動選擇輸入來源。

5. 原生 DDC 診斷與 mapping 掃描

repository 提供與 MacKVM 共用原生 bridge 的獨立診斷程式。可在兩台 Mac 建置相符架構，或在 M5 Pro 建置 universal：

./scripts/build-ddc-diagnostic.sh --arch arm64
./scripts/build-ddc-diagnostic.sh --arch x86_64
./scripts/build-ddc-diagnostic.sh --arch universal

工具會輸出執行與編譯架構、Mac 型號、macOS build、EDID 身份／checksum、原生 transport 與 VCP 0x60 輸入狀態：

./dist/ddc-diagnostic-arm64 > arm64-ddc-report.txt 2>&1
./dist/ddc-diagnostic-x86_64 > x86_64-ddc-report.txt 2>&1

若螢幕接受 I2C 寫入卻沒有切換，明確執行 mapping 掃描：

./dist/ddc-diagnostic-universal --display 1 --scan-inputs \
  --values 15,16,17,18,19,27
硬體注意：掃描會暫時切換螢幕輸入，只有在可以安全切換與還原時才執行。只有 accepted=yes 的讀回才是 mapping 證據；工具不會自動修改 app mapping。按 Ctrl-C 或收到 SIGTERM 時，工具會停止候選值迴圈並嘗試還原原本的值；SIGKILL 無法攔截與還原。本專案實測 MA270U 使用 USB-C VCP 19（0x13）與 HDMI 1 VCP 17（0x11）。

請參閱診斷工具說明與原始碼。

6. 授權 macOS 權限

MacKVM 需要兩台 Mac 都依序完成 Local Network、Input Monitoring 與 Accessibility。這可避免多個 macOS 權限提示重疊。

  1. 點擊選單列的 MacKVM 圖示，在 Set up this Mac 按 Enable Local Network。
  2. 回應 macOS 的本機網路提示後，按 I handled the macOS prompt 才繼續下一步。
  3. 依序按 Request Input Monitoring 與 Request Accessibility，並在 macOS 提示中允許。
  4. 三個必要步驟完成後，在 Control request notifications 按 Enable，並允許選用的通知。建議在第一次遠端控制前完成，避免通知授權提示佔用短暫的控制確認時間；只有按 Enable 才會跳出這個系統授權提示。
  5. 從系統設定回到 MacKVM 時，狀態會自動重新整理；也可按 Refresh setup status。

如果之前按過拒絕、macOS 沒再跳出提示，請在目前步驟按 Settings，然後在系統設定中手動允許 MacKVM。完成本機網路步驟後，Review Local Network Settings 仍會保留；若找不到另一台 Mac，請從這裡確認設定。Local Network 沒有公開的程式內授權查詢 API，所以畫面顯示的是「已檢視」，不是「已授權」。

選單會跟隨 macOS 語言；目前提供 English 與繁體中文資源。三個必要權限的 macOS 說明文字也已翻譯。若曾經拒絕授權而沒有再次跳出提示，請使用對應的 Settings 按鈕。

7. 探索、配對與控制

  1. 確認兩台 Mac 都開著 MacKVM，並在選單的 Nearby Macs 看見對方。
  2. 在其中一台按 Pair。
  3. 比較兩邊的六位數驗證碼是否相同，並確認各自顯示的「對方」裝置名稱正確。接收端在驗證碼相同時按 Accept；發起端比對相同驗證碼後按 Confirm code。
  4. 兩邊的簽署決定都完成後，MacKVM 會自動嘗試建立加密連線；若狀態仍是 idle，請在已配對裝置列按 Connect。
  5. 鍵盤與滑鼠接在 M5 Pro 時，請按 Share keyboard and mouse with [Intel Mac]。新配對的接收端會自動允許該已釘選 Mac；若要每次都確認，請在 Paired device information 關閉 Automatically allow control from this Mac，之後接收端才需按 Allow。未啟用時，即使沒有打開 MacKVM 選單，也會收到 macOS 原生通知，提供 Allow、Deny 與 Review in MacKVM。Review 會開啟明確的 Allow/Deny 對話框；螢幕鎖定時按 Allow 必須先通過 macOS 驗證。

第一次配對後，裝置的公開金鑰會被保存。若看到不預期的裝置名稱或驗證碼不一致，請按 Decline。

8. 裝置資料與支援資訊

配對後，MacKVM 會在本機保存每台裝置的友善名稱、Bonjour 提供的 Mac 型號、最後一次成功完成加密連線的時間，以及固定的 SHA-256 公開金鑰指紋。新配對 的 Mac 預設會啟用無縫控制，也可在每台配對裝置旁關閉。

  1. 在選單的 已配對裝置資訊 查看裝置資料。
  2. 可在 Friendly name 欄位輸入容易辨識的名稱並按 Save；名稱會在重新啟動後保留。
  3. 需要提交問題時按 複製支援資訊，再貼到文字或客服表單。
支援資訊只包含版本、macOS、裝置名稱／型號、連線狀態、UUID 與公開金鑰指紋； 不包含私密金鑰、密碼、憑證或網路端點。請仍在公開論壇貼出前自行檢查內容。

9. 日常操作與安全返回

  • 控制另一台 Mac 時，本機鍵盤與滑鼠輸入會被轉送；除非該已釘選 Mac 已啟用無縫控制，否則接收端按 Allow 前不會開始抑制本機輸入。
  • 通知中的按鈕會帶著該次請求的識別碼與一次性的本機 nonce；請求逾時、取消或連線中斷後，舊通知的按鈕不會重新啟動控制。
  • 控制端按 Return keyboard and mouse to this Mac 可結束共享。
  • 要從 Intel Mac 切回 M5 Pro，接收端按 Return keyboard and mouse to [M5 Mac]，會立即停止注入、釋放可能按住的按鍵／滑鼠按鈕，並通知控制端。
  • M5 Pro 的緊急停止快捷鍵：Control-Option-Command-Escape；全域 Control-Option-Command-K 不必開啟選單即可切換分享，閒置時開始請求、控制中或接收中返回本機／控制端。
  • 網路中斷時，MacKVM 會立刻把鍵盤與滑鼠控制歸還本機，並釋放可能按住的按鍵和滑鼠按鈕。
  • 如果是已連線的 peer 暫時離線，MacKVM 會以 0／1／2／4…30 秒的退避 自動重連；已啟用無縫控制的配對裝置不需再次按 Allow，關閉授權的 裝置才會重新要求控制同意。 手動 Disconnect、Forget 或退出 app 會清除重連意圖。
  • 控制請求會比較兩台 Mac 的協定版本和鍵盤輸入來源。配置不同時會在 Allow 前拒絕；控制中途切換輸入法也會停止遠端輸入，請在兩台選相同輸入來源 後重新請求控制。
  • 想移除已配對裝置，選擇 Forget；之後要重新配對才能連線。

10. P2 實機驗收

這一節必須在實際的 14 吋 M5 Pro、2019 16 吋 Intel MacBook Pro 與 BenQ MA270U 上執行；CI 無法模擬螢幕 DDC/CI、實體 USB switch 或 macOS 隱私權提示。
  1. 在 M5 Pro 執行 arm64 app，在 Intel Mac 執行 x86_64 app；兩台完成本機網路、輸入監控與輔助使用權限後，以相同驗證碼配對。
  2. 使用 One keyboard on M5 Pro (USB-C) 時，把鍵盤與滑鼠接到 M5 Pro 或 MA270U USB hub。確認 M5 Pro 可以發起控制，Intel Mac 可以接收控制，而 Intel Mac 的發起按鈕停用。
  3. 若使用實體 USB switch，兩台都選 External USB switch (bidirectional)，先確認兩個 macOS 都看得到鍵盤與滑鼠，再測試雙向控制。
  4. 觀察 MA270U OSD：USB-C 應顯示 M5 Pro，HDMI 1（或你選定的 HDMI 輸入）應顯示 Intel Mac。DDC/CI 失敗時，改用 OSD 手動切換並記錄診斷文字。
  5. 控制中測試 Return keyboard and mouse to [M5 Mac]、緊急快捷鍵、拔插網路與退出 app；確認本機輸入恢復，沒有按鍵或滑鼠按鈕卡住。

11. 常見問題

看不到另一台 Mac

確認兩台都在同一 Wi-Fi／乙太網路、MacKVM 正在執行，並在 Set up this Mac 完成本機網路步驟。公司或訪客網路可能阻擋 Bonjour 探索。

無法控制，或按鍵沒有反應

確認控制端已授權 Input Monitoring 與 Accessibility（active event tap 需要兩者）、接收端已授權 Accessibility，兩台裝置已完成配對並顯示已連線。配對本身不會授予控制權：請在接有實體鍵盤與滑鼠的 M5 Pro 按 Share keyboard and mouse，再在接收端按 Allow。

收不到控制請求通知

建議先在 Set up this Mac 的 Control request notifications 按 Enable。若之前拒絕，請到「系統設定 → 通知 → MacKVM」開啟通知。通知被停用時，請求仍會保留在 MacKVM 選單／視窗中，KVM 選單列圖示也會加上驚嘆號提醒你處理。

螢幕沒有自動切換

確認螢幕與線材提供 DDC/CI，按 Detect DDC-capable displays 並明確選取螢幕；仍失敗時查看 DDC diagnostic，然後用螢幕 OSD 手動選 USB-C 或 HDMI。

登入後沒有出現圖示

先手動啟動 MacKVM，在選單中重新開啟 Launch MacKVM at Login，並檢查「系統設定 → 一般 → 登入項目」是否需要核准。

啟動時顯示 identity 或 Keychain 不一致

只有在你確定舊 identity 應該被丟棄時，才按錯誤畫面的 Reset this Mac identity。它會刪除本機 identity、Keychain key 與 pairings；退出並重新開啟後，必須在兩台 Mac 重新配對。
